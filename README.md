# Worker Management

Workforce, attendance & wage management system for construction workers.

## Build & Test

```bash
./gradlew test
```

## Project Structure

```
src/main/kotlin/wages/   — Pure business-logic wage calculation engine
src/test/kotlin/wages/   — Unit tests (T-1 through T-15 from docs/rules.md)
docs/                    — Specification and business rules
```
